# TricksterMap 0.3.1

0.3.1 修正地磚逐塊上下顛倒造成的拼接錯亂，並修正圖集匯入的 TIL 儲存方向。
既有原始地圖不需要重畫；若用 0.3.0 或更早版本匯入過自製圖集，請從原圖重新匯入。

完整解壓後啟動同目錄的 `TricksterMap.exe`。保留所有 DLL 與 `zh` 資料夾。
執行 GUI 需要 Windows 與 .NET Framework 4.8；不需要 Python。

## 製圖操作

- 滾輪：以游標位置為中心縮放（1%～1600%）。
- 中鍵、右鍵或空白鍵＋左鍵拖曳：平移畫面。可使用符合視窗、1:1。
- 碰撞頁：切換阻擋／可通行，調整 1～128 格的圓形／方形筆刷；支援復原／重做。
- 精細／簡易模式：隨時切換，保留相同視角。精細模式讀取 LYR／TIL／BAC。
- 地圖場景製作：鋪設、翻轉、擦除地磚，匯入 PNG／BMP 圖集。
- 場景物件：新增、複製、移動、刪除現有 BAC 素材。
- 建立空白地圖時，以現有地圖提供素材庫，再編輯地磚、物件及碰撞。

## EFF 與素材

從「預覽」選單切換「顯示地圖 EFF 特效」；「播放場景動畫」會同時播放場景與粒子。
未播放時，特效顯示一秒取樣畫面。

「特效素材依賴／素材根目錄」會顯示實際引用、缺檔、缺動畫及失效名稱。
必要時選擇含 `data` 的客戶端根目錄，或 `data` 本身。
原作者的絕對路徑只按明確的 `data/...` 後綴解析，不會任意挑選同名檔。

使用「檔案 → 匯出完整遊戲資源包 ZIP」打包目前的地圖四檔、已有的 EFF、指定 NRI 素材與 SHA-256 清單。
缺少必要素材或指定動畫時會拒絕此完整匯出，並列出原因。原本的平面地圖配套匯出仍可使用。
遊戲需配合載入完整 MD3／LYR／TIL／BAC；新圖的 MapInfoEx、NPC、怪物設定需另外處理。
